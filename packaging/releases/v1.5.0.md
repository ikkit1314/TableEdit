## Auto-Fill matches columns and fills several at once

- **Column > Auto-Fill Columns… (Shift+Cmd+F)** now lists every column with a pattern guessed from its name: `SHIPPING_FIRST_NAME` gets `%fname%`, `SHIPPING_ZIP` gets `%zip%`, `Postal Code` gets `%zip%`, `CARD_CVV` gets `%cvv%`, and so on. Edit any pattern, or pick a preset for the selected one.
- Tick as many columns as you like (the selected columns start ticked; **Tick All Matched** ticks every recognised one) and fill them in one step. Every column in a row describes the same made-up person, so the card holder matches the name and the city, state, ZIP and phone area code belong together.
- New tokens: `%street%` `%apt%` `%state%` `%statename%` `%zip%` `%countrycode%` `%phone10%` `%cardtype%` `%cardnumber%` `%cardmonth%` `%cardyear%` `%cardyear4%` `%cvv%`. `%city%` and `%country%` now match the rest of the address. A checkbox switches addresses to Canada. Card numbers are public test numbers.
- **Only empty cells** keeps what's already in each column. One Undo reverts the whole fill.

## Remove duplicate rows two ways

- **Data > Remove Duplicate Rows** drops rows whose every cell matches an earlier one, keeping the first.
- **Data > Remove Rows Duplicated in Current Column** keeps the first row for each value in the current column and removes later rows that repeat it, ignoring empty cells — handy for keyed lists (like an email column) where the whole rows are not identical. Both are a single Undo.

## Insert a row above or below

- **Insert Row Above** and **Insert Row Below** are in the Row menu and the cell right-click menu; right-clicking a cell selects it first, so the new row lands where you clicked. Enter still inserts below. Undoable.

## Paste repeats to fill the selection

- Copy one row, select several rows, and paste: the row repeats down every selected row, spreading right as wide as the copied row. A copied block of several rows repeats the same way; one copied value still fills every selected cell.

## Install

If you have 1.4.0, use **File > Check for Updates…**. Otherwise quit TableEdit, download `TableEdit-1.5.0-macos-arm64.dmg` for Apple Silicon or `TableEdit-1.5.0-macos-x64.dmg` for Intel, open it and drag TableEdit to Applications. Requires macOS 12 or newer.
