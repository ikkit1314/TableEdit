## Open multiple CSVs at once

- Select several files in **File > Open… (Cmd+O)**, open them together from Finder, or drag multiple files into TableEdit. Each CSV opens in its own window.
- Launching TableEdit with several file arguments now opens all of them.
- A window is reserved as soon as loading starts, fixing simultaneous file requests overwriting one another in the same empty window.
- Use **Window** to switch between CSVs or restore a minimized window. **File > New Window (Cmd+N)** creates another blank document.
- Reopening an open or loading CSV focuses its existing window and preserves edits. Unsaved blank documents are not reused. Each document has independent edits, saving, and undo; closing one leaves the other documents open.

## Install

Quit the old TableEdit version. Download `TableEdit-1.3.4-macos-arm64.dmg` for Apple Silicon, or `TableEdit-1.3.4-macos-x64.dmg` for Intel. Open the DMG, drag TableEdit to Applications, eject the image, and launch the installed app. Requires macOS 12 or newer.

The build's actual signing status is appended below. An ad-hoc signed build is not Apple-notarized and may require **System Settings > Privacy & Security > Open Anyway** after a blocked first launch of an installed update. On macOS 12 use System Preferences > Security & Privacy.
