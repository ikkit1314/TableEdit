## Changes

- Find & Replace now offers visible cells, the current column, and a captured cell selection as explicit scopes.
- Finding a match keeps the captured search region. Sorting tracks the original records; filtered-out rows are excluded. Old selections are rejected after changing documents or rebuilding columns.
- Replace one match or all matches within the chosen scope. Each replacement operation supports undo and redo without changing neighboring cells.
- Trim whitespace and change case within selected cells using Data > Selected Cells or the cell context menu.
- Cell edits refresh active search and duplicate filters, including after undo/redo.
