## Paste grows the table

- Pasting a block (Cmd+V) that runs past the last row or column now adds the rows and columns it needs instead of refusing. The trailing blank line from spreadsheet copies is ignored, the pasted area stays selected, and one Undo removes everything the paste added.

## Fill profiles with random data

- **Data > Fill Profiles with Random Data… (Shift+Cmd+P)** recognises profile headers such as `PROFILE_NAME`, `EMAIL`, `SHIPPING_ZIP`, `BILLING_SAME_AS_SHIPPING`, `CARD_CVV`, `First Name` or `Postal Code`, and fills each row with one consistent made-up person: matching city, state, ZIP and phone area code, US or Canadian addresses, and the card holder named after the person.
- By default only empty cells are filled, so pasted emails are kept and used as the profile name. Card numbers are public test numbers, not real cards.

## Software update

- **File > Check for Updates…** compares this version with the latest GitHub release. On a Mac it downloads the right DMG for your chip, checks it against the release's SHA256SUMS.txt, and replaces TableEdit in Applications after you click **Install and Relaunch**. It won't quit while a document has unsaved changes.
- The installed app also checks quietly once a day at launch and only speaks up when there is a newer version. Turn this off in the update dialog, or skip a single version.
- Updating from 1.3.4 or older still needs this one manual install, because those versions don't have the updater yet.

## Install

Quit the old TableEdit version. Download `TableEdit-1.4.0-macos-arm64.dmg` for Apple Silicon, or `TableEdit-1.4.0-macos-x64.dmg` for Intel. Open the DMG, drag TableEdit to Applications, eject the image, and launch the installed app. Requires macOS 12 or newer.

The build's actual signing status is appended below. An ad-hoc signed build is not Apple-notarized and may require **System Settings > Privacy & Security > Open Anyway** after a blocked first launch. On macOS 12 use System Preferences > Security & Privacy.
