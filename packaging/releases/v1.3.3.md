## Changes

- macOS downloads are now DMGs with an Applications link for drag-and-drop installation. Apps and native libraries are signed on a macOS runner before packaging; post-download Terminal signing is no longer required for these DMGs.
- Typing after selecting cells replaces every selected cell with the newly entered value on commit. Enter commits the value; Escape cancels it. The whole change supports one-step undo and redo.
- Column duplicate results now highlight repeated cells in yellow. Selected duplicates use purple so they remain distinguishable. Show All clears the duplicate highlighting.

## Install

Download `TableEdit-1.3.3-macos-arm64.dmg` for Apple Silicon, or `TableEdit-1.3.3-macos-x64.dmg` for Intel. Quit the old version, open the DMG, drag TableEdit to Applications, eject the image, and launch the installed app. Requires macOS 12 or newer.

The actual signing mode is appended below by the release workflow. An **ad-hoc signed** build is not Apple-notarized: macOS may still require **System Settings > Privacy & Security > Open Anyway** after the first blocked launch of the installed app. On macOS 12 use System Preferences > Security & Privacy. Approving that installed copy should allow subsequent launches; a new download can require approval again. A DMG alone does not remove Gatekeeper's developer-trust checks.

The workflow supports Developer ID signing and Apple notarization when the owner configures the repository secrets documented in `packaging/MACOS_RELEASE.md`.

## Validation

75 native Linux mouse/keyboard checks passed; native clipboard round trips remain skipped on the virtual display. The macOS release workflow verifies each app signature, verifies and mounts both DMGs to inspect their apps, and smoke-tests startup of the runner's native architecture. These checks do not replace interactive testing on a user's Mac.
