## Changes

- Select individual cells or rectangular ranges by dragging or Shift-clicking. Extend selection with Shift + arrow keys or Ctrl/Cmd + Shift + arrow keys.
- Select columns with Ctrl + Space and rows with Shift + Space or the row headers.
- Delete selected rows with the toolbar, context menu, or Ctrl/Cmd + Delete/Backspace. Delete alone clears selected cells. Changes support undo.
- Click a column header to toggle ascending and descending sorting.
- Find duplicate values in the selected column, highlight all occurrences, and restore the full table with Show All. Empty values are ignored; matching is case- and whitespace-sensitive.
- Copy, cut, and paste rectangular cell ranges; paste a single value into every selected cell.

## Downloads

- **Apple Silicon (M1/M2/M3/M4 and newer):** `TableEdit-1.3.0-macos-arm64.zip`
- **Intel Mac:** `TableEdit-1.3.0-macos-x64.zip`

Requires macOS 12 or newer. Quit the previous version, unzip the download, and run `first-run.command` before moving `TableEdit.app` to Applications. This helper removes download quarantine and signs the app locally; these builds are not Apple-notarized.

## Validation

Both architectures are built in Release mode and the archives are checked for integrity, version, and executable permissions. The cell interaction suite passed 36 checks on Linux. Native macOS behavior and native clipboard round trips have not been verified in this environment.
