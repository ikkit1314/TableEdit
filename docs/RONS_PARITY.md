# Ron’s Data Edit 操作对照与验收清单

TableEdit 目前没有达到 Ron’s Data Edit 的 1:1。此清单用于记录已实现的范围、代码中确认的限制和后续验收，不代表已经完成与 Ron’s 全部功能的对照。

用户已确认对照新版 **Ron’s Data Edit**。当前环境无法访问 Ron’s 官方产品页面；以下缺口来自 TableEdit 代码审查，不把未经核实的功能当作 Ron’s 的既定行为。精确快捷键、界面布局和完整功能仍需与该产品实测对照。

## 用户已明确要求的操作

| 操作 | 当前实现 | 验收状态 |
| --- | --- | --- |
| 点击选择单元格，而不是自动选中整行 | 自定义单元格选区，原生行选择只跟踪编辑位置 | Linux 交互检查通过；需对照目标版本并在 Mac 验收 |
| 鼠标拖选连续单元格 | 支持正向、反向矩形选区和边缘滚动 | Linux 交互检查通过；Mac 待验收 |
| Shift 点击起点和终点间的区域 | 保留固定起点，扩展矩形选区 | Linux 交互检查通过；Mac 待验收 |
| 键盘扩展选区、选择整列 | Shift+方向键；Ctrl/Cmd+Shift+方向键到表边界；Ctrl+Space 选列 | 已实现；与 Ron’s 遇到空格时的跳转规则尚未对照 |
| 选择整行与删除行 | 行号、Shift 行号范围、工具栏、右键菜单、快捷键；可撤销 | Linux 交互检查通过；Mac 待验收 |
| 点击列头 A→Z / Z→A 排序 | 单列切换升降序；支持恢复原始顺序 | Linux 交互检查通过；目标版本的比较规则待对照 |
| 检查当前列的重复值 | 显示所有重复记录，包括首次出现；忽略空串，区分大小写和空格 | Linux 交互检查通过；匹配选项及结果呈现待对照 |
| 多选后直接输入覆盖全部选中格子 | 用户已确认此规则；1.3.3 输入提交后批量覆盖，Esc 取消，一次撤销恢复各自原值 | Linux 原生键盘检查覆盖矩形、整列、撤销、重做及取消；用户 Mac 待验收 |
| 重复值高亮 | 1.3.3 重复格子标黄、选中的重复格子用紫色；Show All 清除 | Linux 检查覆盖实际格子背景、范围及清除 |

## 第一批：核心编辑流程的已知限制

| 项目 | 代码中确认的现状 | 下一步验收要求 |
| --- | --- | --- |
| 非连续选择 | `CellSelection` 只能保存一个矩形；Ctrl/Cmd 点击不会添加独立区域 | 确认目标版本规则后，覆盖添加、取消、复制、清空、删除及撤销 |
| 选区内批量操作 | 1.3.1 增加选区内查找/计数/替换及去空白、大小写转换；其他数据工具仍各有自己的范围 | 已检查搜索范围不随匹配光标缩小、排序不改变目标记录、过滤隐藏行不被替换、旧文档选区失效；其他工具待统一 |
| 粘贴到表格边界 | 超出行列数会拒绝粘贴，要求先手动插入 | 对照自动扩展、覆盖和填满选区的规则；一个撤销步骤恢复数据和表格大小 |
| 多列操作 | 插入、删除、移动主要针对当前列 | 对照连续/非连续列选择；批量操作不得触碰未选列 |
| 行插入与位置 | 只有向当前行下方插入一行的直接入口 | 对照上方/下方插入、多行数量及筛选/排序后的插入位置 |
| 删除与清空 | 清空单元格和删除整行已分开；删除列只处理当前列 | 核对右键菜单和快捷键；过滤后只操作明确选中的记录 |
| 重复值工具 | 固定单列精确匹配，没有比较规则选项；整行去重是另一个全文操作 | 确认列组合、大小写、空白、保留首项/末项等实际需求和目标版本规则 |
| 编辑导航 | 支持直接输入、双击、F2/Enter、Tab 和方向键；未在 Mac 实测 | 验收编辑提交/取消、换行、Tab/Shift+Tab、输入法及选区内导航 |

## 第二批：需要对照参考软件的范围

这些是待核对项目，不是已经确认 Ron’s 每个版本都提供的功能。

| 范围 | TableEdit 当前状态 |
| --- | --- |
| 列宽、列顺序、隐藏/冻结 | 支持调整列宽和菜单左右移动；没有列头拖动重排、隐藏或冻结入口 |
| 排序与筛选 | 单列排序，关键词/通配符、列范围、取反筛选；没有多列排序条件编辑器 |
| 文件格式控制 | 自动识别分隔符/编码并保留部分格式；没有完整的保存编码、换行和引号选项界面 |
| 数据转换 | 已有去空白、大小写、向下填充、自动填充；没有拆分/合并列或转置入口 |
| 多文件工作流 | 多窗口打开文件；没有标签页、最近文件列表或会话恢复入口 |
| 大文件 | 网格虚拟化与部分后台筛选/排序；仍在内存中保留整个文档，未完成目标规模验收 |
| Mac 体验 | 1.3.3 发布流程改为 macOS 构建、预签名和 DMG 打包，包含签名、挂载和启动冒烟检查；用户 Mac 的 Gatekeeper、剪贴板、输入法及菜单仍需验收。无 Developer ID 和公证时仍需首次启动批准 |

## 完成标准

- 按目标版本逐项记录触发方式、选区、操作结果、边界情况与快捷键；不能以“菜单里有这个功能”作为完成依据。
- 修改数据的操作必须检查撤销/重做，以及筛选和排序后的作用范围。
- 每项分别记录实现状态、自动检查结果和 Mac 人工验收结果。
- Linux 交互套件覆盖基础编辑与选区内批量操作；具体运行方式和当前验证范围见 [tests/README.md](../tests/README.md)。原生剪贴板往返因虚拟显示环境限制跳过，不能记作端到端通过。
- Git 标签、Release 编译、GitHub Release 页面和可下载附件是不同的交付状态；发布完成须确认页面及两个架构的附件。
